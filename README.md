# Activity System Whiteboard

A static shared-screen CHAT whiteboard for the Berkeley Changemaker Gateway.

## Use in class
Choose **Load class case**, then **Present board**. Add and edit notes, drag their top bars, or move a focused handle with arrow keys. Add lightning bolt places an editable lightning-bolt note. Undo reverses changes. Download board saves a JSON copy; Open board restores it. Browser storage is local, not synchronized.

The included class case is an anonymous paraphrase shared with instructor permission. It distinguishes reported framing from questions for collective inquiry. No student submission file or identifying information is included.

## Run locally
From this folder run `python3 -m http.server 8798`, then open http://127.0.0.1:8798/. Keep that terminal running during class.

## GitHub Pages
Upload these files to a repository. In Settings → Pages choose Deploy from a branch, main, /(root). Wait for GitHub to report the actual site URL and verify it before sharing. Public site: https://drc-berkeley.github.io/activity-system-whiteboard/
